# Send one notification per Refresh Run

Superseded for Windows presentation by [0014](0014-group-windows-article-notifications-by-day.md). The lifecycle still makes one atomic notification decision per Refresh Run.

Each Refresh Run will produce at most one Refresh Notification. One eligible Article displays its title and journal, while multiple eligible Articles are summarized by count with at most three title previews; every included Article is marked in one atomic notification decision and activating the notification opens the dashboard.
